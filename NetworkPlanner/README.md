NetworkPlanner
A web-based IP addressing toolkit built with ASP.NET WebForms (.NET Framework 4.7.2). NetworkPlanner lets you calculate subnet information, plan VLSM allocations across multiple departments, and inspect IP addresses in binary — all through a clean terminal-themed interface.
Features

Note-(HTML and CSS visuals are generated by Claude Code. All C# code is self written)

Subnet Calculator — enter any IP/CIDR pair and get the network address, broadcast, host range, wildcard mask, class type, and usable host count
VLSM Calculator — allocate variable-length subnets across multiple departments from a single address block, sorted largest-first for efficient use of space
Binary View — see your IP address and subnet mask broken down bit by bit, with network and host portions clearly distinguished

Getting Started
---------------------------
1. Clone the repository
2. Open the solution in Visual Studio
3. In the Solution Explorer, right-click Dashboard.aspx and select Set As Start Page
4. Press F5 to build and run
